# Skvoz

Skvoz (бывший Zapret App) — пульт для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и локального Telegram-прокси на Windows: скачать и обновлять zapret, подобрать конфиг, запустить обход, проверить доступ к Discord, YouTube и Telegram.

![Windows](https://img.shields.io/badge/Windows-10%2F11-blue) ![License](https://img.shields.io/badge/license-MIT-green)

## Скачать

[**Releases → последняя версия**](https://github.com/ProtheticGlitch/zapret-app/releases/latest)

| Файл | Описание |
|------|----------|
| `Skvoz-Setup-*.exe` | Установщик |
| `Skvoz-*-Portable.exe` | Portable, без установки |

## Как пользоваться

1. Скачайте и запустите exe (или установите через Setup).
2. Подтвердите **UAC** — права администратора обязательны.
3. Если zapret ещё не установлен — нажмите **«Скачать с GitHub»**.
4. Выберите стратегию и нажмите **кнопку питания** (старт обхода).

Portable и установленная версия хранят настройки в `%APPDATA%\zapret-app\`.

> Windows может показать SmartScreen — сборки без платной подписи. Скачивайте только из Releases этого репозитория.

## Требования

- Windows 10/11 (64-bit)
- Права администратора
- Интернет для первой установки zapret

## Свои домены и IP

В настройках приложения:

| Список | Файл |
|--------|------|
| Для обхода | `list-general-user.txt` |
| Исключить домены | `list-exclude-user.txt` |
| Исключить IP | `ipset-exclude-user.txt` |

После изменений: **Стоп → Старт**.

## Telegram proxy

Вкладка **Telegram** запускает локальный MTProto-прокси, который ходит к серверам Telegram через WebSocket.

1. Нажмите **Запустить** (по умолчанию `127.0.0.1`, порт и секрет можно сменить).
2. Нажмите **Открыть в Telegram** или скопируйте ссылку прокси в клиент.

Включённый **Автозапуск прокси** поднимает его вместе с приложением.

## Удобства

- **Проверка доступа** на главной — одной кнопкой проверяет Discord, YouTube и Telegram (через прокси — настоящим MTProto-запросом).
- **Мини-окно у трея** — клик по значку: переключатели обхода и прокси, проверка доступа.
- **Автообновление zapret** — раз в 6 часов ставит новый релиз, свои списки и выбранный конфиг сохраняются, обход перезапускается сам.
- **Горячие клавиши** Ctrl+1…5 — страницы.

## Автозапуск и автоподбор

- **Автозапуск приложения** — открывает Skvoz при входе в Windows (через планировщик задач).
- **Автозапуск обхода** — выключен по умолчанию; при включении запускает zapret при старте приложения (и включает автозапуск приложения).
- **Автоподбор конфига** — проверяет все `.bat` и выбирает лучший при первом запуске.
